  support). Every other plan is a class-string or prop-value edit only.
- Run `npx tsc --noEmit && npx eslint .` after each plan; run `npm run build` once after all of
  001, 002, and 005 have landed (the only three whose Tailwind arbitrary-value syntax needs a
  real build to confirm it resolved correctly, per each plan's own Verification section).
